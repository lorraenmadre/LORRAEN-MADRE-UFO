Foreword

Why a cookbook

Most technology guides are written for the people who built the technology. This book is written for the rest of the family: the godmother who keeps every birthday card, the aunty who runs the household on a paper calendar, the cousin who closes the laptop the second a black window opens. Recipes work because they tell you what you need, what to do with your hands, and what it should look like when it's right.

Dice, our AI bot extension, reads every recipe with you and will soon live on your computer as a little assistant you can ask questions. Dice doesn't take over the stove. Dice points, explains, and waits for you.

Chapter I · Recipe No. 1

Your own AI workspace

Prep10 min
Cook30–45 min
Serves1 computer
DifficultyMedium

Odysseus is a free AI workspace that runs on your own computer instead of someone else's. You'll copy a few short lines into a program called Terminal (PowerShell on Windows). Every step says what it does and what you should see.

Ingredients

  • A Mac or Windows PC, ideally with 16 GB of memory (8 GB works, slowly).
  • 20 GB of free space.
  • A steady internet connection.
  • Pen and paper for the admin password you'll make. There's no "forgot password" email later.

Kitchen rule: paste one grey box at a time, press Return, and wait for the line ending in $ (or > on Windows) to come back before the next one.

Which kitchen is yours?

Not sure which Mac? Apple menu (top-left) → About This Mac. Chip: Apple M1 (or M2, M3, M4) means Apple chip. Processor: Intel means Intel.

Method

  1. Open Terminal

    Press ⌘ + Space, type Terminal, press Return.

  2. Install Homebrew

    Homebrew is the standard Mac tool installer. Odysseus uses it to fetch its parts.

    Terminal
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    Heads up: it asks for your Mac login password; nothing appears as you type. At the end it shows Next steps with two or three lines. Run those too.

  3. Download Odysseus

    If a box offers "command line developer tools," click Install, wait, then paste this again.

    Terminal
    cd ~
git clone --branch main https://github.com/odysseus-dev/odysseus.git

    You should see: "Receiving objects… done."

  4. Start it and make your password

    Press Return to keep the username admin, then type the password you wrote down.

    Terminal
    cd ~/odysseus
./start-macos.sh

  5. Serve

    Leave Terminal open, then visit this address and sign in as admin.

    Browser address
    http://127.0.0.1:7860

Method

Intel Macs skip Homebrew, which no longer supports them. Same dish, a few more steps.

  1. Get a newer Python

    At python.org/downloads/macos, download the newest Python 3.13 "macOS 64-bit universal2 installer" and click through. Then double-click Install Certificates.command in the window that opens.

  2. Open Terminal and check

    Terminal
    python3.13 --version

    You should see: Python 3.13. and a number.

  3. Download Odysseus

    Terminal
    cd ~
git clone --branch main https://github.com/odysseus-dev/odysseus.git

  4. Set out its own mixing bowl

    A private space for Odysseus's parts. Afterward your prompt starts with (venv).

    Terminal
    cd ~/odysseus
python3.13 -m venv venv
source venv/bin/activate
pip install --upgrade pip

  5. Add the ingredients

    A few minutes of scrolling text. That's normal.

    Terminal
    pip install -r requirements.txt

    You should see: "Successfully installed…" If there's red text about cryptography, see "When the soufflé falls" below.

  6. Make your password

    Terminal
    python setup.py

  7. Serve

    Leave this window open, then visit http://127.0.0.1:7860.

    Terminal
    python -m uvicorn app:app --host 127.0.0.1 --port 7860

Method

The Odysseus team tests Windows less than Mac, so expect the odd lump in the batter.

  1. Install two helpers

    Git for Windows from git-scm.com and Python 3.12 from python.org. On Python's first screen, tick "Add python.exe to PATH".

  2. Open PowerShell

    Start → type PowerShell → open it.

  3. Download Odysseus

    PowerShell
    cd ~
git clone --branch main https://github.com/odysseus-dev/odysseus.git

  4. Start it and make your password

    PowerShell
    cd ~\odysseus
powershell -ExecutionPolicy Bypass -File .\launch-windows.ps1

  5. Serve

    Browser address
    http://localhost:7000

To finish: give it a brain

  • Easiest, any computer: get an API key from a model service such as OpenRouter or OpenAI and paste it into Odysseus Settings. Costs a little per message.
  • Free and private, newer computers: install Ollama from ollama.com and add http://localhost:11434/v1 in Settings.

Leftovers: turning it on again

Mac with Apple chip
cd ~/odysseus && ./start-macos.sh
Mac with Intel chip
cd ~/odysseus && source venv/bin/activate && python -m uvicorn app:app --host 127.0.0.1 --port 7860
Windows
cd ~\odysseus; powershell -ExecutionPolicy Bypass -File .\launch-windows.ps1

Recipe No. 1 · Notes

When the soufflé falls

It happens to every cook. Here's what I see most.

docker: command not found

That was a Docker recipe from another guide. You don't need Docker; use the recipe for your computer above.

Homebrew on macOS is only supported on Apple Silicon

Your Mac has an Intel chip. Switch to the Intel tab.

Python says 3.9.6

Install Python 3.13 (Intel step 1) and type python3.13 instead of python3.

Failed building wheel for cryptography

One security ingredient has no ready-made version for your Mac. Use a slightly older ready-made one, then add the ingredients again:

Terminal
pip install "cryptography<50" --only-binary=cryptography
pip install -r requirements.txt

If it says "No matching distribution found," ask for help and share the last few lines.

No module named 'httpx'

The ingredients step didn't finish. Find the red error above it, fix that, then run pip install -r requirements.txt again.

I forgot my admin password

Nobody can look it up. On a fresh install, close Odysseus (Control + C) and make a new one:

Terminal
cd ~/odysseus
mv data/auth.json data/auth.json.old
python setup.py

Note: this resets every account on that Odysseus.

localhost:7000 won't open on my Mac

Macs use 7000 for AirPlay. Use http://127.0.0.1:7860.

I typed my password at the regular prompt

It went nowhere, but Terminal remembers it. Clear that, and change the password if you use it elsewhere.

Terminal
history -c

Before you cook anything

Kitchen safety

  • Lines starting with # in other guides are notes. Don't paste them.
  • Download Odysseus only from github.com/odysseus-dev/odysseus. There's no installer file or app-store version.
  • Setup help is never something you have to pay for.
  • Connect email, files, and calendar to any AI one at a time, after you're comfortable with it.
  • Never share your passwords, API keys, or a file named .env.
  • The paperwork recipes show you how to keep documents safe and findable. Wills, trusts, and deeds themselves are for your attorney.
